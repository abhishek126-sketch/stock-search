Set up “Update now”

Prices refresh automatically every ~5 min in market hours. “Update now” asks GitHub to run the refresh immediately, which needs your own token:

  1. Open github.com/settings/personal-access-tokens/new (signed in as abhishek126-sketch).
  2. Token name: Stock Search update · Expiration: 90 days (or your choice).
  3. Resource owner: abhishek126-sketch.
  4. Repository access: Only select repositories → stock-search.
  5. Permissions → Repository permissions → Actions: Read and write (Metadata: Read-only is added automatically). Nothing else.
  6. Generate token, copy it (starts with github_pat_), paste into ⚙ Settings here and Save.

The token stays in this browser only. Revoke anytime on the same GitHub page.
